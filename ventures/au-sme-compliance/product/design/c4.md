## PII and Sensitive Data Map

| Data Element | Classification | Where Stored | Retention | Encryption |
|-------------|---------------|-------------|-----------|-----------|
| User email | PII | users table | Until account deletion | At rest (DB encryption) |
| Business name | PII | accounts table | Until account deletion | At rest |
| Employee names/IDs (from CSV) | PII + SENSITIVE-PAYROLL | employee_records table + uploaded CSV in storage | 90 days from upload | AES-256 at rest; in-transit TLS 1.3 |
| Employee pay rates (from CSV) | SENSITIVE-PAYROLL | employee_records table | 90 days from upload | AES-256 at rest; in-transit TLS 1.3 |
| Employee job titles (from CSV) | PII + SENSITIVE-PAYROLL | employee_records table | 90 days from upload | AES-256 at rest |
| Uploaded CSV file | PII + SENSITIVE-PAYROLL | Object storage (encrypted) | 90 days; auto-deleted | AES-256 at rest |
| Generated PDF report | Contains PII | Object storage (encrypted) | 90 days | AES-256 at rest |
| IP address (audit log) | PII | audit_log table | 12 months | At rest |
| Stripe customer/subscription IDs | Financial reference | accounts table | Until account deletion | At rest |

> No payroll data is sent to external systems other than storage. Stripe receives only billing data (email, card). Email provider receives only email address and first name. FWC data is curated by the operator and stored internally — no outbound call to FWC/FWO at runtime.
