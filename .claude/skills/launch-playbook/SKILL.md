## Procedure
1. Pick the 2–3 launch channels that match where the ICP already is (don't spread thin).
2. Sequence it: pre-launch (waitlist/validation), launch, post-launch follow-up. Tie to the pre-build willingness-to-pay validation from `advisory/` if still open.
3. List the assets each channel needs (copy, visuals, landing page) and who/what produces them.
4. Define the metrics that say the launch worked, and the kill/iterate trigger.
5. Add a PUBLISH CHECKLIST: every external post needs explicit human approval and must pass the no-overclaim / no-off-limits-claim check.
6. Write to `marketing/launch.md`.

Heuristics: `knowledge/ledger.md`.
