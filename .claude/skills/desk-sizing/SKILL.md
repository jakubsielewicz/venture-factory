when_to_use: the cheap (~6 hr) desk pass that gates whether a venture earns a paid demand test — turns keyword volume + community pain threads + competitor gaps into a PASS/CONDITIONAL/KILL with reusable landing-copy and pricing inputs.
allowed-tools: Read, Write, WebSearch, WebFetch

## Procedure
Output → `ventures/<slug>/research/phase0/`: one CSV per tab + `go-no-go.md`. Log a URL + date for every row. Tab schemas & thresholds: `references/workbook-spec.md`.

1. **Keywords (Block 1, ~2h).** Pull AU monthly volume + CPC + competition for the seed cluster (Tier 1 tool-intent, Tier 2 problem-intent, Tier 3 long-tail). If Google Ads Keyword Planner is unavailable, triangulate from free tools + Google autocomplete/PAA and **label every volume an estimate** in `source`. Flag ambiguous-intent terms (weight 25% or exclude). Harvest autocomplete + PAA; mark PAA questions with weak answers as SEO wins. **Weighted cluster = full Tier 1 + full Tier 2 + 50% Tier 3, excluding flagged terms.** Also compute a widen-the-wedge cluster (broader adjacent framing) as fallback. → `keywords.csv`.
2. **Communities (Block 2, ~2.5h) — the heart.** Enumerate Reddit/forums/Discord/Facebook/YouTube channels; record members + activity; **read and quote each self-promo rule**; grade A/B/C. Mine pain threads by running the fixed search-term set **per community, logging each query with hit/no-hit** so "no signal" is reproducible, never asserted. Log every genuine pain thread (hours / $ / confusion / fear) with a **verbatim quote** and the accepted answer. **Target ≥15 threads across ≥3 distinct communities.** Sum A/B reachable population. → `communities.csv`, `evidence-log.csv`.
3. **Competitors (Block 3, ~1h).** For each incumbent: changelog + forum, log every options/feature request and **the age of the oldest unshipped-but-acknowledged one** (older = stronger gap evidence); record pricing. Check US analogues for the target-market gap (differentiation sentence). Google the **accountant anchor** (4–5 firms + fee range) — this independently evidences the WTP claim and frames your price as cheap. List tripwires (Google Alerts + monthly changelog check). → `competitors.csv`, `accountant-anchor.md`.
4. **Summary + decide (Block 4, ~30m).** Fill the Summary tab against thresholds (`references/workbook-spec.md`): weighted cluster **≥1,500/mo PASS · 800–1,500 CONDITIONAL · <800** needs community rescue. **Proceed** if search PASSES, or CONDITIONAL *and* pain-thread evidence passes strongly (≥15/≥3). **If both miss:** run the **widen-the-wedge fallback** (rebuild the cluster around the broader adjacent buyer, options/premium as hero tier); if the widened cluster clears **3,000+/mo**, proceed with the broader framing. Only after the fallback also misses → KILL.
5. **Write the one-paragraph go/no-go** in `go-no-go.md`: the weighted number, the **three strongest verbatim quotes** (they become landing copy), the sharpest risk observed, and the call. This paragraph is the input to the next phase.

Do NOT fabricate volumes or quotes; `unknown`/`no-hit` are valid cells. A KILL on desk evidence is a win — it saved the build. Heuristics: `knowledge/ledger.md`.
