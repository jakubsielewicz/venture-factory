## Procedure
1. Test each candidate moat — proprietary data, network effects, switching costs, brand/distribution, regulatory/licensing barrier, integration depth, cost advantage — and rate it absent / weak / real.
2. Run the **12-month copy test**: if a funded competitor (or the platform you sit on) tried to clone this, what actually stops them? Write the honest answer.
3. Distinguish a feature (will be subsumed) from a product from a business.
4. Verdict: durable / defensible-for-now / commodity. Name the one moat worth investing to deepen.

Be skeptical — most ideas have no moat at G0, and that's fine if payback is fast; say so explicitly rather than inventing one. Heuristics: `knowledge/ledger.md`.
